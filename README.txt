TIỆM ẢO ẢNH - PHIÊN BẢN GIAO DIỆN BÁM THEO CODE GỐC

1. Trang chủ:
   index.html
   - Sidebar đen 300px bên trái
   - Logo phía trên
   - Menu chữ in hoa, letter-spacing
   - Gallery 4 cột bên phải
   - Hover ảnh + chữ VIEW
   - Bấm ảnh mở lightbox

2. Ảnh sản phẩm:
   san-pham.html
   - Bấm "ẢNH SẢN PHẨM" trên menu sẽ sang trang này.
   - Đặt ảnh vào images/san-pham/
   - Tên: san-pham-01.jpg, san-pham-02.jpg, ...

3. Các trang khác:
   food.html -> images/food/
   mooncake.html -> images/mooncake/
   doanh-nghiep.html -> images/doanh-nghiep/

4. Logo:
   Đặt logo thật của bạn vào:
   images/logo.png

5. Ảnh trang chủ:
   Đặt vào:
   images/home/
   Tên:
   home-01.jpg
   home-02.jpg
   ...

6. Muốn thêm ảnh:
   Mở file HTML tương ứng và copy thêm một khối:
   <li class="masonry-box"> ... </li>

7. Website không còn phụ thuộc vào Chimkudo/WordPress.
